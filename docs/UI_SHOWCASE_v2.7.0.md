## 🎨 四、UI 设计特点

### 4.1 配色方案

| 用途 | 颜色 | HEX 值 | 示例 |
|------|------|--------|------|
| **主色调** | 深紫蓝 | `#1a237e` | 标题、按钮 |
| **渐变色** | 紫蓝渐变 | `#667eea → #764ba2` | 背景 |
| **严重** | 红色 | `#d32f2f` | 高危漏洞标记 |
| **高危** | 橙色 | `#f57c00` | 高危漏洞标记 |
| **中危** | 黄色 | `#fbc02d` | 中危漏洞标记 |
| **低危** | 绿色 | `#388e3c` | 低危漏洞标记 |
| **R155** | 紫色 | `#667eea` | 合规卡片 |

### 4.2 交互特性

- ✅ **实时 WebSocket 连接** - 扫描进度实时更新
- ✅ **响应式设计** - 适配桌面/平板/手机
- ✅ **图表可视化** - Chart.js 柱状图/饼图/折线图/雷达图
- ✅ **数据筛选** - 按时间/严重程度/固件类型筛选
- ✅ **导出功能** - Excel/PDF 一键导出
- ✅ **WebSocket 状态指示器** - 右下角实时显示连接状态

### 4.3 报告模板

| 模板 | 用途 | 内容 | 适用场景 |
|------|------|------|---------|
| **简版** | 快速浏览 | 仅关键 CVE 摘要 | 每日站会 |

| **详细** | 审计报告 | 执行摘要 + 建议 + 组件 | 客户交付 |
| **高管** | 管理层 | 风险评分 + 摘要 | 高层汇报 |

## 🔧 六、技术栈

### 前端
- **框架**: Vanilla JavaScript (无框架)
- **样式**: 自定义 CSS + 渐变色
- **图表**: Chart.js (柱状图/饼图/折线图/雷达图)
- **实时通信**: Socket.IO v4.7.4
- **PDF 导出**: jsPDF + html2canvas
- **Excel 导出**: SheetJS (xlsx)

### 后端
- **框架**: FastAPI
- **模板引擎**: Jinja2
- **报告生成**: 自定义 HTML 模板 + PDF 渲染
- **实时推送**: python-socketio 5.x
