## 🐛 常见问题排查

### Q1: 暗色主题不生效？

**解决方案:**
```bash
# 清除浏览器缓存
Ctrl+Shift+Delete (Windows/Linux)
Cmd+Shift+Delete (Mac)

# 或强制刷新
Ctrl+F5 (Windows/Linux)
Cmd+Shift+R (Mac)
```

**代码检查:**
```javascript
// 检查 localStorage
localStorage.getItem('theme')
// 应返回 'light' 或 'dark'
```

### Q2: 新图表不显示？

**检查步骤:**
1. 打开浏览器控制台 (F12)
2. 检查 Console 选项卡是否有错误
3. 检查 Network 选项卡确认 JS 文件加载成功

**常见错误:**
- Chart.js CDN 未加载 → 检查网络连接
- scanData 为空 → 先完成一次扫描
- Canvas 元素不存在 → 检查 HTML 结构

### Q3: 快捷键无效？

**可能原因:**
- 焦点在输入框内
- 与浏览器快捷键冲突
- 操作系统快捷键占用

**解决方案:**
- 点击页面空白处后再试
- 更改浏览器设置禁用冲突的快捷键
- Mac 用户确保系统快捷键未占用

### Q4: Toast 通知不消失？

**解决方案:**
```javascript
// 手动清除所有通知
document.querySelectorAll('.notification').forEach(n => n.remove());
```
