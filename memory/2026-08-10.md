## 🔧 技术亮点

### 1. 智能降级机制

```javascript
// 优先尝试服务器端 API
const response = await fetch('/api/report/pdf', ...);

if (!response.ok) {
    // 服务器失败，自动切换到客户端生成
    await generateClientSidePDF(scanId);
}
```

**优势**:
- ✨ 用户体验无感知降级
- 🚀 保持功能可用性
- 💡 兼顾性能和可靠性

### 2. 高质量 PDF 生成

```javascript
const canvas = await html2canvas(exportContainer, {
    scale: 2,              // 2 倍清晰度
    useCORS: true,         // 支持跨域资源
    logging: false         // 静音模式
});
```

**效果**:
- 📄 清晰打印效果
- 🎨 保留所有样式
- 📏 标准 A4 纸张比例

### 3. 内存友好设计

```javascript
// 使用临时容器并立即移除
document.body.appendChild(exportContainer);
// ... 处理
document.body.removeChild(exportContainer);  // 清理
```

**好处**:
- ♻️ 避免内存泄漏
- 🔒 数据安全（不持久存储）
- ⚡ 性能优化

## 📝 笔记

### 关于 CDN 选择

选择了 cloudflare cdnjs:
- 全球 CDN，速度快
- 高可用性强
- HTTPS 支持
- 广泛使用的版本稳定

替代方案：
- jsdelivr: `https://cdn.jsdelivr.net/npm/jspdf@2.5.1/dist/jspdf.umd.min.js`
- unpkg: `https://unpkg.com/jspdf@2.5.1/dist/jspdf.umd.min.js`

### 关于 PDF 质量权衡

当前设置：
- scale: 2 (2 倍分辨率)
- PNG 格式
- 单次截图

可调整参数：
- scale: 1-4 (越大越清晰但越慢)
- backgroundColor: '#ffffff' (白色背景)
- logging: true (调试时使用)
