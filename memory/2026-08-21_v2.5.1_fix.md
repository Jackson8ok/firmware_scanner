## 二、修复内容

### 1. grype_matcher.py `_convert_match_to_vulnerability()`

**CVSS 修复**:
```python
# v2.5.0 (错误)
cvss_score = float(cvss_entry.get("baseScore", 0.0))

# v2.5.1 (正确)
metrics = cvss_entry.get("metrics", {})
cvss_score = float(metrics.get("baseScore", 0.0))
```

**EPSS 修复**:
```python
# v2.5.0 (错误)
epss_score = None  # 直接置 None

# v2.5.1 (正确)
epss_list = vuln_data.get("epss", [])
if isinstance(epss_list, list) and len(epss_list) > 0:
    epss_entry = epss_list[0]
    epss_score = float(epss_entry.get("epss"))
```

**Date 修复**:
```python
# v2.5.0 (错误)
published_date = self._parse_date(vuln_data.get("publishedDate"))  # grype 无此字段

# v2.5.1 (正确)
published_date = self._get_published_date_from_db(cve_id)  # 从 Grype DB 补查
```

# 修复两处硬编码
