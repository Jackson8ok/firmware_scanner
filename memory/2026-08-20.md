### 经验总结

**Lesson Learned**:
- `create_release.sh` 首次创建时如果 notes_file 参数传递有问题，会使用默认描述
- 已存在的 Release 可以用 PATCH 更新：`/releases/{release_id}`
- 更新 Body 需要 JSON 转义，用 `python3 -c "import sys,json; print(json.dumps(sys.stdin.read()))"` 最可靠

**Skill 使用**:
```bash
# 创建 Release
bash /mnt/workspace/qwenpaw_workspaces/workspaces/default/skills/github_auto_release/create_release.sh \
  Jackson8ok/firmware_scanner \
  v2.5.0 \
  "v2.5.0 - grype CLI 集成与结果合并" \
  "$(pwd)/RELEASE_NOTES_v2.5.0.md"

# 如果 Release 已存在，更新 Body
TOKEN=$(cat /mnt/workspace/.github_token)
RELEASE_ID=$(curl -s -H "Authorization: Bearer $TOKEN" "https://api.github.com/repos/Jackson8ok/firmware_scanner/releases/tags/v2.5.0" | python3 -c "import sys,json; print(json.load(sys.stdin)['id'])")
BODY=$(cat RELEASE_NOTES_v2.5.0.md | python3 -c "import sys,json; print(json.dumps(sys.stdin.read()))")
curl -s -X PATCH -H "Authorization: Bearer $TOKEN" -H "Accept: application/vnd.github+json" -H "Content-Type: application/json" \
  "https://api.github.com/repos/Jackson8ok/firmware_scanner/releases/$RELEASE_ID" \
  -d "{\"body\": $BODY}"
```
